## Deployment

1. Connect this repository to **Cloudflare Pages**
2. Build settings: Framework = None, Output directory = `/`
3. Add custom domain
4. (Optional) Add Workers for form handling at `/api/contact`

- Tailwind CSS (CDN)
- Font Awesome 6
- Semantic HTML5 + Schema.org
